# Graphics Assets Guide

## Required Icons

The extension needs the following icon sizes in `icons/` folder:

- `icon16.png` - 16x16 pixels (extension toolbar, context menus)
- `icon32.png` - 32x32 pixels (Windows HiDPI, Retina displays)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Recommended: Create Proper Icons

For best results, create a square PNG icon with:
- Transparent background or solid dark background (#1e1e2e)
- Simple, recognizable design (bookmark or home icon)
- Visible at small sizes (16x16)

You can use tools like:
- Figma (free)
- Canva (free)
- Photoshop/GIMP
- Online icon generators

### Current Status

## Chrome Web Store Graphics

### Screenshots (Required: 1-5 images)
**Size:** 1280x800 or 640x400 (JPEG or PNG, no transparency)

Suggested screenshots:
1. Main view with tabs and bookmark grid
2. Explorer view showing folder tree navigation
3. Settings page showing customization options
4. Context menu demonstrating bookmark editing
5. Search results view

### Small Promo Tile (Optional)
**Size:** 440x280 pixels (JPEG or PNG)
Used in Chrome Web Store featured section

### Large Promo Tile (Optional)
**Size:** 1400x560 pixels (JPEG or PNG)
Used on Chrome Web Store homepage
